# guide-adaptive-compute — Project Instructions

## Architecture
Single-file guide (README.md) — no deploy artifacts, no SQL scripts, no application code.

## Conventions
- All SQL examples use placeholder `MY_WAREHOUSE` / `my_warehouse`
- Performance framing: "better performance at similar costs" — never "cheaper"
- Audience: Snowflake admin who already understands standard warehouses

## Key Commands
- No deployment — read-only guide
- Verify: `cat guide-adaptive-compute/README.md | wc -l` (target < 300 lines)
